# ChatToHarness 0.8.3

## 简体中文

本版为桌面应用追加当前仓库的稳定版更新来源，同时保留原有发布来源，并让当前仓库的 Pages 下载与 Release 安装包保持一致。

- 自动更新继续检查 `DJ-Huang/ChatToHarness`，并追加检查 `watermoon/ChatToHarness`；程序选择版本最高且校验通过的稳定版安装包，版本相同时仍优先原来源。
- 每个来源分别固定 GitHub API、Release 页面和安装包下载根地址；跨仓库页面或下载链接会被拒绝。
- 两个来源都沿用平台、文件大小与 SHA-256 校验，并支持受限的 `SHA256SUMS.txt` 回退；检查更新不会自动下载安装包。
- 当前仓库的 Pages 构建使用当前仓库已公开的稳定 Release，并在部署后验证中英日页面及真实下载链接，避免继续指向其他仓库或旧版本。

升级说明：已经发布的 0.8.2 仍只检查原有更新来源，因此无法自动发现仅发布在 `watermoon/ChatToHarness` 的 0.8.3。请从当前仓库 Release 或 Pages 手动安装 0.8.3 一次；从本版开始，后续检查会同时使用两个来源。安装后如客户端缓存了旧工具定义，请刷新工具列表或重新连接 Harness。

Windows x64 安装包默认未签名；macOS arm64 DMG 使用临时签名，未进行 Apple 公证。系统可能警告或阻止安装。macOS 最低要求为 14.0。自动化与隔离窗口验收不等于所有真实设备、网络和安装环境均已验证。

## English

This release appends the current repository as a stable desktop-update source without replacing the original source, and aligns this repository's Pages downloads with its published Release assets.

- The updater continues to check `DJ-Huang/ChatToHarness` and additionally checks `watermoon/ChatToHarness`. It selects the highest validated stable installer and keeps the original source first when versions tie.
- Each source has its own fixed GitHub API, Release page, and installer-download roots. Cross-repository release or asset URLs are rejected.
- Platform, file-size, and SHA-256 verification remain mandatory for both sources, with a bounded `SHA256SUMS.txt` fallback. Checking never downloads or installs automatically.
- This repository's Pages build now uses stable Releases published by this repository and verifies the live English, Chinese, and Japanese download links after deployment.

Upgrading: the already-published 0.8.2 build checks only the original update source, so it cannot automatically discover 0.8.3 when this release exists only under `watermoon/ChatToHarness`. Install 0.8.3 once from this repository's Release or Pages site; subsequent checks from this version use both sources. Refresh the client tool catalog or reconnect Harness if the client still caches older tool definitions.

The Windows x64 installer is unsigned. The macOS arm64 DMG is ad-hoc signed and not notarized; OS warnings or restrictions may apply. Minimum macOS version: 14.0. Automated and isolated-window acceptance does not establish compatibility with every device, network, or installation environment.

## 日本語

このリリースでは、従来の配布元を置き換えずに現在のリポジトリをデスクトップ更新元として追加し、このリポジトリの Pages ダウンロードを公開 Release のインストーラーに合わせます。

- 更新確認は従来の `DJ-Huang/ChatToHarness` を維持し、`watermoon/ChatToHarness` も追加で確認します。検証済みの最も新しい安定版を選び、同じ版なら従来の配布元を優先します。
- 各配布元の GitHub API、Release ページ、インストーラーダウンロードのルートを個別に固定し、別リポジトリを指すページやアセット URL を拒否します。
- どちらの配布元でもプラットフォーム、ファイルサイズ、SHA-256 を検証し、上限付きの `SHA256SUMS.txt` フォールバックも利用できます。更新確認だけで自動ダウンロードやインストールは行いません。
- 現在のリポジトリの Pages は、このリポジトリで公開された安定版 Release を使用し、配布後に英語・中国語・日本語の実ダウンロードリンクを検証します。

更新時の注意：公開済みの 0.8.2 は従来の更新元だけを確認するため、`watermoon/ChatToHarness` のみに公開された 0.8.3 を自動検出できません。現在のリポジトリの Release または Pages から 0.8.3 を一度手動でインストールしてください。本版以降は両方の配布元を確認します。クライアントに古いツール定義が残る場合は、ツール一覧を更新するか Harness に再接続してください。

Windows x64 は未署名、macOS arm64 DMG はアドホック署名のみで公証されていません。OS が警告または制限する場合があります。macOS 14.0 以降が必要です。自動テストと隔離ウィンドウの検証は、すべての端末、ネットワーク、インストール環境での動作を保証しません。
