# ChatToHarness 0.8.2

## 简体中文

本版改进 Cloudflare MCP 统一多设备连接、设备工具授权及断线恢复。

- Cloudflare MCP 与安全通道配置在同一右侧设置页面中分别切换；本机工具授权为独立左侧菜单及完整工具列表页面。
- 本机 MCP 工具服务与传统 Secure MCP Tunnel 生命周期解耦：断开传统安全通道不会清空 Cloudflare 的本机工具目录。
- Cloudflare Agent 增加连接/注册超时、心跳与超时重连、重连状态提示，以及最长约 30 秒的指数退避。
- 设备重连先提交工具目录版本号，仅在版本变化或云端缺失时同步完整目录。
- Cloudflare 路由可让尚未分发的只读请求短暂等待设备恢复，执行类操作不排队也不自动重放。
- 执行类工具增加 `operation_id` 持久去重；新增 `get_operation_status` 查询原调用状态，长任务可保留 `task_id` 用于恢复查询。
- 修复测试客户端覆盖生产连接、云端工具目录授权模式及多语言配置页面等问题。

升级说明：Cloudflare Worker 已升级，客户端仍须安装 0.8.2 才能使用新的版本握手、连接心跳及独立工具生命周期。请在 ChatGPT 中刷新统一 MCP 插件工具清单，以使用 `get_operation_status`。自动重连不代表对写文件、命令执行和 Computer Use 等有副作用的操作进行自动重试。

Windows x64 安装包默认未签名；macOS arm64 DMG 使用临时签名，未进行 Apple 公证。系统可能警告或阻止安装。macOS 最低要求为 14.0。CI/隔离验收并不等于所有远程设备和真实网络场景已经完成验证。

## English

This release improves unified multi-device Cloudflare MCP routing, local tool authorization, and recovery from lost connections.

- Cloudflare MCP and Secure Tunnel are sibling choices within the same settings page. Local Tool Authorization has its own full-width page.
- Local MCP tool availability no longer depends on the lifecycle of the legacy Secure MCP Tunnel.
- Cloudflare Agents use registration timeouts, heartbeats, reconnect watchdogs, and capped exponential backoff.
- Reconnects exchange the catalog version first; full catalogs are uploaded only when missing or changed.
- Strictly read-only, not-yet-delivered calls may wait briefly for reconnection. Mutating calls are never blindly queued or replayed.
- Durable `operation_id` receipts prevent duplicate mutation execution; `get_operation_status` reports recorded status, including supported task IDs.
- Improvements to production/test-agent isolation, local grants and multilingual settings.

To use the new client-side reconnection and catalog capabilities, install version 0.8.2. Refresh the unified MCP plugin tool list in ChatGPT to discover `get_operation_status`. Auto-reconnect does not imply automatic retries of commands, file writes or Computer Use.

The Windows x64 installer is unsigned. The macOS arm64 DMG is ad-hoc signed and not notarized; OS warnings or restrictions may apply. Minimum macOS version: 14.0. Automated acceptance does not establish real-world reliability on every device or network.

## 日本語

このリリースでは、Cloudflare MCP の複数端末接続、ローカルツールの権限設定、接続断からの復旧を改善しました。

- Cloudflare MCP 設定と Secure Tunnel 設定を同じ画面内の切り替えタブに整理し、ローカルツール権限を独立した画面に移動しました。
- ローカル MCP ツールを従来の Secure Tunnel の接続状態から独立させました。
- Agent に登録タイムアウト、ハートビート、接続復旧と指数バックオフを追加しました。
- 再接続時はツール一覧のバージョンを先に照合し、必要時のみ一覧全体を同期します。
- 安全な読み取り専用要求は短時間の再接続待ちを許可し、変更操作は自動再実行しません。
- `operation_id` による重複防止と `get_operation_status` による実行状態の照会を追加しました。
- テスト用接続と本番接続の分離、権限管理、多言語設定を改善しました。

新しいクライアント機能には 0.8.2 のインストールが必要です。ChatGPT 側で MCP ツール一覧を更新してください。Windows x64 は未署名、macOS arm64 はアドホック署名のみで公証されていません。macOS 14.0 以降が必要です。
